# MiniNav 紧凑导航与卡片状态设计

## 目标

降低页面滚动时的顶部占用，把搜索、常用状态和备注放回最适合的位置，同时补齐 MiniNav 自有站点图标，并把 README 改造成个人维护手册。

## 已确认范围

- 删除 QuickBar，页面只保留一条 56px 高的置顶菜单栏。
- 搜索整合进菜单栏，手机端在同一行切换搜索状态，不增加高度。
- 点击次数达到 3 次的书签显示火苗；手动置顶改为“重点”图钉。
- 火苗和图钉不改变分组或书签顺序。
- 卡片第二行始终显示网址，备注通过独立按钮和浮层查看。
- 制作 MiniNav 自有图标，同时用于浏览器和菜单栏。
- README 面向个人维护，不再承担公开项目宣传页职责。

## 单层菜单栏

`NavHeader` 接管搜索状态。电脑端搜索框位于标题和操作区之间，宽度保持在 200 至 256px；手机端显示搜索按钮，点击后用搜索框替换标题和右侧操作区，菜单栏高度保持 56px。搜索支持清空和 Escape 退出。

`QuickBar` 组件和相关测试删除。`useActiveGroup` 不再测量第二层置顶导航，分组跳转和 IntersectionObserver 偏移仅基于菜单栏实际底部。桌面侧边栏继续使用 `top-14`，分组顺序保持固定。

## 卡片状态

`BookmarkCard` 直接根据现有数据渲染状态：

- `clicks >= 3` 显示火苗，并提供“常用，已打开 N 次”的可访问说明。
- `pinned === true` 显示图钉，并将管理操作文案改为“标记重点”或“取消重点”。
- 状态徽标位于卡片右上区域；管理操作出现时使用稳定的尾部空间，不能与徽标重叠。

不新增最近访问时间，不生成访问历史，不根据点击次数或重点状态自动排序。

## 备注浮层

网址域名始终显示在卡片第二行。有备注时显示备注按钮：

- 鼠标悬浮或键盘聚焦时打开。
- 触屏点击时切换打开状态。
- 失焦、点击其他区域或按 Escape 时关闭。
- 操作备注按钮不会触发卡片打开或增加点击次数。

浮层右对齐卡片，限制为视口内最大宽度；文本自动换行，超过最大高度后内部滚动。使用本地轻量组件实现，不重新引入 Radix Tooltip。

## MiniNav 图标

图标采用“房屋轮廓 + 导航网格”的简洁组合，使用石墨色底、白色主体和暖色强调块，保证 16px 至 32px 下仍可识别。生成高分辨率 PNG 源图，并派生浏览器 favicon 和 Apple Touch Icon。Next.js metadata 显式声明图标，同时在菜单栏标题左侧显示小尺寸品牌图标。旧 v0 和 placeholder 图标资产移除。

## 测试与验收

- 组件测试覆盖桌面搜索、手机搜索、清空和 Escape。
- 集成测试确认 QuickBar 消失且仅剩一层置顶导航。
- 卡片测试覆盖火苗阈值、重点图钉、网址恒显、备注鼠标/键盘/触屏交互及事件隔离。
- 运行 Vitest、TypeScript、ESLint 和 Next.js 生产构建。
- 在 1440x900 与 390x844 视口检查滚动占用、菜单溢出、卡片徽标重叠和备注浮层越界。

## 非目标

- 不修改分组顺序或书签顺序策略。
- 不增加访问历史、时间戳或自动排序。
- 不修改云端数据格式。
- 不重新引入大型 UI 组件库。
